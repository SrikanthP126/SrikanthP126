## Hi, I am Srikanth Penta

**Senior AI Engineer** · Agentic systems, Text-to-SQL and RAG on governed enterprise data · Microsoft Azure and AWS

I build LLM systems that hold up in production: agent workflows and retrieval that respect enterprise permissions, with evaluation and tracing designed in from day one. I spent my first years building .NET services and cloud infrastructure before moving into applied AI, so I care as much about RBAC, private endpoints and audit logs as I do about prompts and retrieval quality.

- **Agentic AI platforms:** LangGraph and AutoGen orchestration, skill governance, and feedback-to-skill pipelines with human review
- **Text-to-SQL and RAG:** plain-English access to governed data through read-only, row-level-secured agent tools, and hybrid retrieval with BM25, semantic ranking and reranking
- **Evaluation and observability:** LLM-as-a-Judge, grounding and hallucination-risk checks, Arize Phoenix and Langfuse tracing
- **AI infrastructure:** Terraform-provisioned Azure OpenAI and Azure ML under zero-trust controls
